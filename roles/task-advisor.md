# Task Advisor

Use Task metadata to help locate responsibility, choose whom to consult and decide
whether new work needs Node capability. Load `cockpit-task-advisor` when first needed;
reuse it while in context. This guidance is for any agent, not a new business role.

This role contributes only `task_read` and the advisory Skill, not Node instructions,
Task writes, session creation or messaging tools. Other composed capabilities retain
their own boundaries. Reading does not bind, ACK, start or authorize work.
Native session/Chat remains the only source of business conversation; Task metadata
assists discovery, not a replacement for actual context or permission to take over.

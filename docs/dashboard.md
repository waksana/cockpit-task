# Cockpit Task 工作台

工作台是工作记录的只读视图，不是调度台，也不推断会话是否正在运行。
视觉采用浅灰背景、白色内容面板、统一间距与细边框；参考 Portfolio 的布局与主题，
不包含其业务代码、金融数据或外部字体、分析服务和组件库。

## 阅读顺序

页面采用一个纵向分组清单：**正在做 → 待办 → 待决定 → 受阻 → 暂缓 / 待发布 → 完成历史**。
每组独立读取与加载更早记录，待办保留登记顺序，其余保留服务返回的活动顺序。
不会为没有优先级字段的记录创造分数，也不会让完成历史占用其他分组的额度。

顶部概览呈现当前搜索下四个重点分组的**已加载条数**，不是全量统计。
`10+` 表示已经加载 10 条且服务返回下一页；加载更多后数字随之更新。
点击概览项或阶段筛选可专注一个分组；搜索始终覆盖六个分组，包括完成历史。
“最近读取”是页面成功读取时间；任务行的“记录更新”来自服务 `updatedAt`。

任务行限制标题与摘要各两行，完整内容在详情显示。详情保留目标、范围、验收、授权、
前置条件及其绑定版本、登记来源、结果链接、历史 owner 引用和分页进展。
技术 ID 放在次要折叠区域，任务 ID 可复制；非 HTTP(S) 的结果路径只显示为文本。
窄屏按同一顺序堆叠，结果与来源在进展历史前显示。

## 导航与更新

`?task=<id>` 深链接仍可直接打开，进入页面后转为 hash 导航。
任务标题是可键盘访问的原生链接；浏览器前进/后退与“返回工作清单”均可使用。
返回时保留搜索、阶段筛选、各组已加载记录以及清单滚动位置。

SSE 更新自动重读清单和已展开的分页，不把旧状态合并为新事实。
已打开的详情保留阅读位置与展开内容，并提示可以读取最新详情，避免更新打断阅读。
加载失败显示错误与重试入口，搜索无结果与分组无记录有独立提示。
访问失效会清空页面数据，仅提供重新打开当前页面的链接；工作台不提供任何认证管理。

## 隔离预览

从仓库运行：

```sh
node test/dashboard-preview.js web 18797
```

打开 `http://127.0.0.1:18797/` 或 `http://127.0.0.1:18797/?task=demo-blocked-0`。
此服务仅绑定 loopback，数据全部来自 `test/dashboard-fixture.js` 的合成记录，不连接业务数据库。
可追加 `--expanded` 参数，为每组生成 12 条合成记录以演练独立分页。
可将另一个已提交版本的 `web` 目录作为第一个参数，以相同记录作前后比较。
预览端点 `/preview/changed` 只向预览页面发送合成 SSE 事件，不包含在生产服务中。

前端回归覆盖分组顺序、真实加载数量、筛选、搜索、独立分页、深链接与返回、依赖、
来源、历史 owner、错误、访问失效、SSE 和异步响应竞态：

```sh
node --test test/dashboard.test.js test/gateway.test.js test/dependencies.test.js
```

生产访问保护和交付方式仍分别遵循 [HTTPS 工作页](passkey-access.md) 与
[Task delivery](DELIVERY.md)；本次改版没有修改服务端权限、任务模型或发布流程。
